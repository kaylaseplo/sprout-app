# Vision

Sprout is the teacher's assistant that never clocks out.

## The problem

Early childhood education is one of the most demanding and underserved professions. Nursery teachers are responsible for the development, safety, and documentation of many children at once, yet the tools they're given are built for administrators and parents, not for them. Activity planning happens from scratch daily, documentation competes with being present, institutional knowledge walks out the door when staff leave, and new teachers have no in-the-moment support.

## The solution

An AI-powered classroom assistant for nursery/daycare teachers that reduces the documentation burden, supports teachers in the moment, and builds institutional knowledge over time — so great teaching doesn't disappear when staff turn over.

## Who it's for

- Primary buyer: nursery/daycare director
- Primary user: classroom teacher
- NOT parents — they stay in existing tools like Brightwheel

## The four core features (built in phases)

1. Behavior & Development Chat — in-the-moment expert guidance for teachers
2. Classrooms & rosters — the structure everything else hangs on
3. Activity Generator — age-appropriate, supply-aware, avoids repeats, learns from ratings
4. Smart Photo Documentation — snap, voice-tag, AI-drafted caption, save (the differentiator)

## The bigger picture

Sprout is also a serious learning project: real auth, a real database, secure server-side AI calls, and file storage. It's a step up from the toddler-toolkit prototype toward a production-shaped application.

## What Sprout is not
- Not a parent communication platform (complements Brightwheel, doesn't replace it)
- Not a billing or admin tool
- Not a facial recognition system — child privacy is non-negotiable
